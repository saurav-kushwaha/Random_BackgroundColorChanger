
# Random Background Color Changer
This project is a simple web application that changes the background color randomly. It is built using JavaScript, CSS, and HTML.

#Features
Randomly changes the background color of the webpage.
Simple and easy to use.

#Installation
1. Clone the repository:
git clone https://github.com/saurav-kushwaha/Random_BackgroundColorChanger.git

2. Navigate to the project directory:
cd Random_BackgroundColorChanger

3. Open index.html in your web browser to see the application in action.

#Usage
Simply open the index.html file in any web browser.
Click start button to change the background color randomly
Click Stop button to stop
